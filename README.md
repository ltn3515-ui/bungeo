# 내 동네 붕어빵 타이쿤 v0.8 — 테스트 제품판

## GitHub · Vercel 웹 미리보기

GitHub 저장소를 Vercel의 **New Project**에서 가져오면 `vercel.json`에 따라 `npm run build:web`으로 빌드하고 `dist`를 공개합니다. `main`에 새 커밋을 올릴 때마다 웹 미리보기가 갱신됩니다. 이 URL은 일반 브라우저용 게임 미리보기이며 앱인토스 `.ait` 업로드·심사와는 별개입니다. 앱인토스용 번들은 로컬에서 `npm run build`로 만듭니다.

웹 미리보기는 HTTPS 환경에서 홈 화면 설치를 지원합니다. 설정의 **홈 화면에 설치** 버튼이 표시되면 누르고, 표시되지 않는 브라우저에서는 공유/메뉴의 **홈 화면에 추가**를 사용하세요. 첫 방문이 끝난 뒤 게임 리소스를 저장해 오프라인에서도 실행합니다. 게임 기록은 브라우저/설치 앱의 로컬 저장 공간에 남으므로 기기나 브라우저를 바꾸면 공유되지 않습니다. 앱인토스 안에서는 웹 설치 기능을 실행하지 않습니다.

## 가장 쉽게 테스트하기 (Windows)

1. ZIP 압축을 푼 뒤 `bungeo-town` 폴더의 `미리보기_실행.bat`을 더블클릭합니다. **Node.js 20 이상**이 설치돼 있어야 합니다.
2. 자동으로 열리는 `http://localhost:4173`에서 플레이합니다. 종료할 때 명령창을 닫습니다.
3. 스마트폰 테스트는 PC와 같은 Wi-Fi에 연결하고 `http://PC의_내부_IP:4173`으로 접속합니다. 방화벽 허용 여부와 PC IP를 확인하세요. 이 방식은 일반 웹 미리보기이며 토스 앱 환경 테스트를 대신하지 않습니다.
4. 개발자는 `npm install` → `npm run dev`로 소스를 실행할 수 있습니다. `npm run build`는 `dist/`와 `bungeo-town.ait`를 생성합니다.

## 들어간 기능

- 실제 지도·GPS 대신 넓은 2D 일러스트 골목 지도와 동네 이름 선택: 화면 이동, 확대·축소, 현재 가게로 이동
- 가상 상인 세 명과 주간 골목 대결: 직접 판매 100점, 완벽 굽기 +60점, 알바 응대 45점, 주문 실패 -60점(최저 0점), 기기 현지 시각 월요일 0시 점수 초기화
- 겨울 골목·손님·붕어빵 화로 일러스트를 실제 플레이 배경으로 적용 (`public/alley-art.webp`)
- 지도 시안을 실제 탐험 지도로 적용 (`public/town-map.webp`): 여덟 장소의 마커를 누르면 이동하거나 다음 분점을 열 수 있어요. v0.3 저장 기록은 그대로 이어집니다.
- 이미지 위에 동작하는 주문 말풍선, 실시간 굽기 게이지, 주문·굽기·건네기 조작부 및 현재 순위판
- 골목마다 별도로 발생하는 손님 주문과 실시간 남은 시간, 긴급 주문 알림. 가게를 늘리면 주문 빈도가 높아지고 기다리는 시간이 짧아져요.
- 팥·슈크림·초코가 각각 다른 속도로 익으며 주문 대기 시간과 완벽 굽기 구간·타는 지점이 다릅니다. 화면에는 현재 재료의 기준과 움직이는 보너스 구간이 표시됩니다.
- 완벽 굽기 게이지는 슈크림이 앞, 팥이 중간, 초코가 뒤에 위치합니다. 주문을 받은 뒤 화로 속도를 천천히(0.75배)·기본(1배)·빠르게(1.35배) 중에서 바꾸면 매번 주간 점수 20점이 차감됩니다. **열기 올리기** 버튼은 열기 +11에 주간 점수 10점을 사용합니다. 점수가 부족하면 두 조작을 사용할 수 없고 기본 속도로 자동 조리됩니다.
- 직접 구운 주문을 10개 연속 성공할 때마다 모든 재료의 기본 굽기 속도가 10%씩 빨라집니다(최대 50개 연속, +50%). 실패하면 연속 기록이 0으로 돌아갑니다. 알바가 처리한 주문은 연속 기록에 더하지 않습니다.
- 손님 말풍선 주문, 굽기 게이지, 적정 구간 판매 보너스, 주문을 놓치거나 태우면 주간 대결 점수 차감
- 상점에서 골목당 한 명의 알바를 게임머니로 일회성 고용. 알바는 8초 후 그 골목 주문을 자동 응대하며 직접 플레이보다 점수와 게임머니 보상이 낮아요.
- 화로·간판·장식 각 4단계 강화와 여덟 골목 분점
- 장사 화면 밖에서는 주문 시계가 멈추며, 앱 종료 중 최대 4시간의 방치 수익, 누적 판매·매출 기록
- 효과음 끄기, 게임 안내, 종료, 초기화, SDK 네이티브 저장소와 게임 유저 키 발급 시도
- 주문·접수·굽기·완벽 구간·시간 초과·판매·알바·강화·분점별 짧은 자체 합성 효과음. 처음 화면을 누른 뒤부터 재생되며 설정에서 끌 수 있어요.
- 현금 거래, 지도 API, 위치 권한, 광고, 유료 아이템 없음

## 재료별 굽기 기준 (화로 열기 수치)

| 재료 | 주문 대기 시간 | 틱당 굽기 속도(기본 화로) | 건넬 수 있는 열기 | 완벽 굽기 | 타는 지점 |
| --- | --- | ---: | ---: | ---: | ---: |
| 팥 | 기본 +2초 | +2.15/0.2초 | 54부터 | 68–88 | 112 |
| 슈크림 | 기본 -1초 | +3.1/0.2초 | 40부터 | 54–70 | 100 |
| 초코 | 기본과 동일 | +2.45/0.2초 | 72부터 | 90–108 | 124 |

기본 주문 대기 시간은 가게 수에 따라 29초에서 약 20초까지 줄어듭니다. 화로 강화·연속 성공·속도 선택에 따라 굽기 속도가 바뀌고, 완벽 구간의 수치는 유지됩니다. 화면에 표시되는 열기는 실제 조리 온도가 아닌 게임 내 게이지입니다. 기존 저장 기록의 연속 성공은 0개부터 시작합니다.

## 앱인토스 등록 전에

`apps-in-toss.config.ts`의 `appName: 'bungeo-town'`은 임시 값입니다. 콘솔에 등록한 고유 ID로 바꾸고 다시 빌드해야 합니다. 게임 이름·아이콘·설명·주요 기능을 콘솔에 입력하세요. 현재 `.ait`는 QR 실기기 테스트와 심사를 통과한 출시 버전이 아닙니다.

사업 형태에 해당하는 게임제작업 등록과 게임물 등급분류를 확인하세요. 앱인토스 게임 출시 가이드에 따라 토스 실기기에서 로딩, 식별키, 저장·재접속, Safe Area, 시스템 뒤로가기·닫기, 오디오, 실제 기기 성능을 확인해야 합니다. 아래 기준은 바뀔 수 있으므로 제출 시 최신 문서를 다시 보세요.

- https://developers-apps-in-toss.toss.im/checklist/app-game
- https://developers-apps-in-toss.toss.im/documentation/common/screen/safe-area
- https://developers-apps-in-toss.toss.im/documentation/integration/sdk-3.x

현재 게임 진행은 기기별 저장입니다. 다른 기기에서 이어하기·실제 이용자 랭킹·서버 동기화는 다음 단계입니다. 현재 순위표의 상대는 고정 점수의 가상 상인이며 외부 사용자의 기록을 가져오지 않습니다. 게임머니 ‘냥’은 게임 내부 수치이며 현금 교환은 지원하지 않습니다. 알바 고용도 현금 결제가 아닌 게임머니만 사용합니다.
